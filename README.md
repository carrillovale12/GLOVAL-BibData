# GLOVAL-BibData
GLOVAL-BibData is an open-source, web-based toolkit developed to support bibliometric analysis and PRISMA-based systematic reviews. Running on Google Colab, it integrates, standardizes, and processes bibliographic data in .bib format from Web of Science and Scopus, generating reproducible datasets for evidence synthesis.

Description: 
GLOVAL-BibData is an open-source, web-based toolkit developed to support bibliometric analysis and PRISMA-based systematic reviews. Running on Google Colab, it integrates, standardizes, and processes bibliographic data in .bib format from Web of Science and Scopus, generating reproducible datasets for evidence synthesis. 

General Objetive:
To develop an open-source, web-based toolkit that automates the integration, processing, and bibliometric analysis of bibliographic data in .bib format from Web of Science and Scopus, while supporting PRISMA-based systematic review workflows in a reproducible and user-friendly environment.

General Specific
Import, merge, standardize, and clean bibliographic records exported from Web of Science and Scopus in .bib format, thereby creating a unified and consistent database.
Automatically detect and remove duplicate records and generate datasets suitable for bibliometric analyses and PRISMA-based systematic reviews.
Provide an accessible workflow that enables reproducible bibliometric analyses and allows for the visualization of metadata for subsequent use in scientific research.
